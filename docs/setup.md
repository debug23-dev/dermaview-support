# Setup
1. Open the app and register a staff account at `/register`. Pick **admin** for the first account.
2. Sign in — you land on `/dashboard`.
3. Add patients at `/patients/new`.
4. Create screening cases at `/screening/new`.
5. Model files: see `docs/model_files.md`. Until installed, cases save without predictions.

Backend (database, auth, storage) is provisioned automatically — no external accounts or env setup.
